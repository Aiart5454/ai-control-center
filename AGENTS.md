# Engineering rules

1. Не хранить секреты, токены, пароли и Tailscale credentials в git.
2. API по умолчанию bind только на 127.0.0.1.
3. Никакого endpoint для произвольного shell.
4. Управление процессами/службами только через фиксированный allowlist.
5. Любая операция start/stop/restart должна возвращать структурированный результат и писать audit event.
6. Не считать отсутствующую аппаратную метрику нулём: возвращать null/unavailable.
7. Android-клиент не получает root/SSH-доступ к серверу.
8. До фактического теста на EVO-X2 не утверждать поддержку конкретных AMD/ROCm датчиков.
9. Сначала безопасный MVP: status + health + read-only telemetry; переключение режимов подключать отдельным этапом.
10. Любой dangerous/system-changing шаг должен быть документирован и иметь способ отключения/отката.
